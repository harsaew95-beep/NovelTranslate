# Запуск на Render Free с iPhone

Это подготовленный к размещению прототип. Живая работа ChatGPT/Gemini и потребление памяти на Render ещё не проверены. Для запуска не нужен компьютер; понадобятся аккаунты GitHub и Render, затем ручной вход в один из чатов.

## 1. Загрузить файлы в GitHub

1. Скачайте архив `novel-reader-render.zip` из чата. В Safari он попадёт в «Файлы» → «Загрузки».
2. Нажмите архив в приложении «Файлы», чтобы распаковать его. Для Render в нём специально нет вложенных папок с исходниками.
3. Откройте https://github.com/new в Safari. Создайте репозиторий `novel-reader`, желательно Private. Добавьте README при создании, чтобы получить доступ к меню загрузки файлов.
4. В репозитории выберите **Add file → Upload files** (при необходимости включите в Safari «Запросить настольный веб-сайт»).
5. Выберите распакованные файлы, а не сам ZIP. Загрузите все файлы из папки. Если GitHub предупредит о замене README, используйте README из архива.
6. Нажмите **Commit changes**. Проверьте, что `Dockerfile`, `requirements.txt`, `server.py`, `browser_chat.py`, `remote_login.py`, `index.html` и остальные файлы интерфейса лежат в корне репозитория.

Ничего из data, пароли и профили браузера загружать не нужно; в архив их нет. При загрузке через «Файлы» скрытые .dockerignore/.gitignore могут не отображаться — для этого чистого архива это не помешает первому запуску.

## 2. Создать сервис Render

1. Откройте https://dashboard.render.com и войдите/зарегистрируйтесь.
2. Выберите **New → Web Service** и подключите созданный GitHub-репозиторий. Для частного репозитория разрешите Render доступ именно к нему.
3. Имя — любое доступное, например `quiet-chapter`. Язык/Runtime — **Docker**. Если не определился автоматически, укажите путь к Dockerfile: `./Dockerfile`.
4. Root Directory оставьте пустым, Docker Command тоже пустым. Выберите **Free**, не платный Starter.
5. В Environment добавьте **READER_PASSWORD** — придумайте длинный пароль для доступа к читалке. Это не пароль от ChatGPT/Gemini; не отправляйте его в чат и не записывайте в GitHub.
6. Добавьте **HOST** = `0.0.0.0`. PORT Render задаёт самостоятельно; программа его читает.
7. В дополнительных настройках Health Check Path укажите `/healthz`, если это поле доступно.
8. Нажмите **Deploy Web Service**, дождитесь состояния Live. Сборка скачивает Chromium и системные библиотеки, поэтому первый запуск может занять несколько минут.
9. Откройте HTTPS-ссылку `https://…onrender.com`, которую выдаст Render. Имя пользователя — **reader**, пароль — ваш READER_PASSWORD.

Вместо ручной настройки можно выбрать **New → Blueprint** и использовать render.yaml: в нём явно стоит plan: free, а READER_PASSWORD будет сгенерирован Render. После создания найдите его в Environment сервиса. Не создавайте одновременно Blueprint и отдельный Web Service: для проекта нужен один сервис.

Официальные инструкции: https://render.com/docs/docker и https://render.com/docs/free.

## 3. Войти в ChatGPT или Gemini с телефона

1. В меню читалки нажмите **«Войти в ChatGPT / Gemini»**.
2. Выберите один сервис и нажмите **«Открыть чат»**. Сначала тестируйте только один сервис, чтобы выяснить, работает ли такой вход.
3. Дождитесь изображения страницы. Это интерактивный снимок браузера на Render, который обновляется примерно раз в 5 секунд; иногда нужен дополнительный тап по «Обновить экран».
4. Нажмите нужное поле на изображении. Введите email/пароль/код в поле под экраном и нажмите **«Ввести текст»**. Для перехода к следующему шагу нажмите Enter или нужную кнопку на изображении.
5. Доступны Tab, Backspace, «Выбрать всё» и прокрутка. Для страницы с MFA или проверкой входа выполните необходимые действия вручную. Подтверждения на другом устройстве выполняются там, где их запросит провайдер.
6. Когда обычный чат открыт и готов, нажмите **«Завершить вход»** и дождитесь сообщения о закрытии браузера. Затем вернитесь к читалке. Эта кнопка закрывает окно и сохраняет локальный профиль; она не проверяет успешность авторизации.

Окно закрывается через 10 минут, чтобы случайно не оставлять браузер работающим. Читалка и экран входа защищены одним паролем. Ввод передаётся вашему серверу и далее странице чата; не используйте чужой экземпляр этого приложения. Текст ввода и снимки не записываются приложением в файлы/журналы. Сам провайдер чата обрабатывает данные входа по своим правилам.

Если появляется «Этот браузер небезопасен», запрет автоматизированного входа или неисправимая проверка, этот способ на данном сервере не заработал. Обход таких ограничений не реализован.

## 4. Проверить перевод

1. Добавьте сначала короткий текст в несколько абзацев и сохраните главу.
2. Выберите сервис, куда вошли, запустите перевод. Во время перевода ручное окно входа должно быть закрыто. Браузер используется один, параллельные переводы идут по очереди.
3. Дождитесь результата на открытой странице. В обычном Render Free при остановке сервера задание может потеряться, поэтому обещания фоновой работы после закрытия Safari нет.
4. При успехе проверьте русский текст, затем попробуйте целую главу Royal Road.
5. Нажмите **↓ TXT** и сохраните текст в «Файлы» iPhone. Его можно читать часами независимо от Render. Либо через меню «Поделиться» сохраните полученный TXT в свой Google Диск. Автоматическое подключение Drive пока не реализовано.

В Safari можно добавить HTTPS-ссылку читалки через «Поделиться → На экран Домой». Сам сайт требует интернет; сохранённый TXT можно открыть без него.

## Если что-то не работает

- **Сайт просит пароль:** пользователь reader; пароль задаётся в Environment → READER_PASSWORD. Это обычное окно Basic Auth браузера.
- **Сервис не запускается:** откройте Render → сервис → Logs. Проверьте, что выбран Docker и задан READER_PASSWORD. Если отсутствует файл интерфейса, загрузите все файлы архива в корень репозитория.
- **503 / холодный запуск:** подождите пробуждения бесплатного сервиса и обновите страницу.
- **Out of memory / код 137 / внезапный рестарт:** вероятно, не хватило 512 МБ для Chromium и страницы чата. Это граница пригодности Render Free, а не проблема сохранения перевода. Скриншотный интерфейс обходится без тяжёлого рабочего стола, но успешный запуск в этих ресурсах не гарантирован.
- **«Поле чата не найдено»:** откройте вход заново и проверьте аккаунт/лимиты/страницу. Возможно изменение интерфейса провайдера — селекторы в browser_chat.py потребуют обновления.
- **Перевод не завершён:** проверьте чат перед повтором. Автоповтора нет, чтобы не расходовать лимиты чата дважды. При ошибке части целиком готовый перевод не сохраняется.
- **Данные исчезли:** Render Free теряет локальную SQLite-библиотеку и браузерные профили при остановке/перезапуске. Войдите снова, добавьте главу и повторите перевод. TXT на телефоне не затрагивается.

Не публикуйте пароли, cookies или снимки страницы с кодами входа при отправке журналов для диагностики.
