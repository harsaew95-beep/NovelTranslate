# Тихая глава

Личная читалка для iPhone и Windows с автоматическим переводом через обычные чаты ChatGPT/Gemini. API провайдеров и ключи не используются.

**Размещение на Render Free без компьютера: [RENDER.md](RENDER.md).**

Подготовлены Dockerfile, render.yaml с планом free и защищённый паролем экран входа `/login`. Он показывает страницу удалённого Chromium и принимает нажатия/ввод с iPhone без VNC и дополнительного рабочего стола. Вход и перевод используют один браузер по очереди. После каждой операции Chromium закрывается; профиль сохраняется в data до остановки сервера.

## Возможности

- Импорт открытых глав Royal Road, ручная вставка для остальных сайтов.
- Перевод через ChatGPT или Gemini в отдельном серверном профиле браузера.
- Очередь переводов, индикация прогресса, отсутствие автоматических повторов после ошибок.
- Сохранение библиотечных записей в локальной SQLite, переключение оригинал/перевод.
- Интерфейс для телефона, тёмная тема, размер шрифта, экспорт отображаемого текста в TXT.
- Manifest и режим отдельного окна при добавлении на экран Домой; офлайн-режим сайта не реализован.

## Ограничения

Реальный вход в ChatGPT/Gemini и перевод на Render Free **ещё не проверены**. Сервисы могут не разрешить автоматизированный браузер, запросить ручную проверку или изменить интерфейс. Обход проверок не реализован. Ответы появятся в истории выбранного аккаунта; действуют его ограничения и правила.

Памяти Render Free может не хватить для страницы чата. Данные и вход теряются при остановке бесплатного сервера; скачивайте TXT на телефон. Автоматическая интеграция Google Диска не реализована. Открытая глава остаётся отображаться в Safari, но это не постоянная офлайн-копия.

Длинный текст делится на части по 7000 символов, без отдельного глоссария. Полнота ответа проверяется маркерами и стабильностью текста, что не гарантирует полноту самого перевода. Все части должны успешно завершиться до сохранения результата. При ошибке старый перевод остаётся в базе, если сам сервер не потерял диск.

## Локальная разработка

Python 3.10+; рекомендуется отдельное виртуальное окружение:

```sh
pip install -r requirements.txt
python -m playwright install chromium
python server.py
```

Откройте http://127.0.0.1:8000, затем `/login` для входа. Альтернативный ручной вход на машине с графическим интерфейсом: `python browser_chat.py chatgpt` или `python browser_chat.py gemini` (не во время запущенного перевода/входа). Docker устанавливает только headless Chromium; команда с графическим окном предназначена для локальной установки полного браузера.

Параметры: PORT (8000), HOST (127.0.0.1), READER_PASSWORD (обязателен при доступе с других устройств). На Render HOST=0.0.0.0, PORT назначается платформой. Логин читалки — reader. Нужен один экземпляр приложения: профили браузера нельзя делить между несколькими процессами.

Исходный проект хранит интерфейс в static/. Специальный архив для загрузки с iPhone содержит файлы в корне; сервер поддерживает обе раскладки. data содержит библиотеку и профили сессий, не публикуйте её. .gitignore и .dockerignore исключают эти данные.

## Проверка

```sh
python -m unittest discover -s tests -v
node --check static/app.js
node --check static/login.js
python -m py_compile server.py browser_chat.py remote_login.py
```

Пройдены 15 локальных тестов: парсер, URL, части текста, очередь и ошибки, маркеры завершения, защита входа/снимков, запрет межсайтового управления и жизненный цикл удалённого браузера с подставным Playwright.

В среде разработки запрещён серверный сокет и недоступен Docker daemon; установка Playwright также блокируется сетью. Docker-сборка, реальный браузер, Safari и размещение на Render здесь не проверены. Файлы подготовлены к публикации, но сайт пока не опубликован.
